# Lift

A personal, offline-first hypertrophy workout tracker. Built as a PWA
(Vite + React + TypeScript) and deployed to GitHub Pages.

Full usage docs are added in phase 8. Quick start:

```bash
npm install
npm run dev      # local dev server
npm run build    # production build into dist/
npm test         # unit tests (phase 9)
```

Deployed automatically to GitHub Pages by `.github/workflows/deploy.yml` on
push to `main`. Set the repo's Pages source to "GitHub Actions".
